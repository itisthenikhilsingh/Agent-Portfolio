# Nikhil Singh — Portfolio

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Vite serves the portfolio at the local URL printed in the terminal.

## Validate and build

```sh
npm run lint
npm run build
npm run preview
```

Static site files, including images, the resume, and the swarm animation
engine, are served from `public/`.
